# 다리마티 허브

우리가 만든 웹페이지·대시보드·도구를 한 곳에 모아 보는 페이지.

**라이브**: https://company-dari.github.io/darimati-hub/

## 무엇인가

- 카테고리(광고·성장 / 판매·재고 / F45 / 브랜드 웹 / 업무관리 / 데이터·도구)로 필터
- 이름·목적·태그·담당자로 검색
- 카드마다 **목적 한 줄 요약 · 담당자 · 상태 배지**
- 모바일 우선 — 폰에서 열어 바로 해당 대시보드로 이동

## 배지 뜻

| 배지 | 뜻 |
|---|---|
| `어디서든` | 폰·PC 어디서나 열림 |
| `PC 전용` | 맥에서 로컬 서버로 도는 페이지. 폰에서는 실행 명령어만 안내 |
| `구글시트` / `관리자` | 외부 서비스 |
| `점검 필요` | 지금 문제가 있는 것 |
| `정리 대상` | 계속 쓸지 판단이 필요한 것 |
| 🔒 `내부` | 구글시트·관리자 링크. PIN을 넣어야 주소가 보임 |

## 🔒 내부 링크

이 repo는 public이라, 내부 링크(구글시트·관리자 주소)는 **PIN으로 XOR 암호화해서** 넣었다.
PIN을 모르면 소스를 봐도 주소를 복원할 수 없다. 한 번 입력하면 그 기기 localStorage에 기억된다.

> 강력한 보안이 아니라 "URL만 아는 사람이 우연히 들여다보는 것"을 막는 수준. 진짜 접근 권한은 각 서비스(구글·메타 등) 계정 권한이 통제한다.

## 담당자 편집

카드의 👤 배지를 누르면 담당자를 고칠 수 있다. 그 기기 localStorage에 저장된다(기기 간 공유 안 됨).
전 기기 공통으로 바꾸려면 `build_hub.py`의 `owner` 값을 고쳐 다시 배포.

## 수정·재배포

소스는 빌드 스크립트 하나로 관리한다. 카드 추가/수정은 `build_hub.py`의 `ITEMS` 배열만 고치면 된다.

```bash
python3 build_hub.py          # → hub/index.html 생성
git add -A && git commit -m "..." && git push
```

PIN을 바꾸려면 `build_hub.py` 맨 위 `PIN` 값을 고치고 다시 빌드·배포.

클로드에게 "허브에 ○○ 추가해줘"라고 말하면 위 과정을 대신 해준다.
